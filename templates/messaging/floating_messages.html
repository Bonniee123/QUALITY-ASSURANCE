{% load static %} {% comment %} Floating Messages dock. This is the floating button in the bottom-right corner of every page. It used to be the QA Assistant widget and nothing else; it is now Messages, so that direct messaging -- the thing people actually need from any page -- is one click away instead of a trip to the Messages page. The assistant was not removed: it is the first conversation in the list, and opening it gives the same chat it always gave, against the same endpoint. Nothing here is a second implementation of messaging. The dock calls the same endpoints the Messages page calls (messaging:sync, messaging:thread_detail, messaging:message_send, messaging:thread_start, messaging:people), so the same server-side rule decides everything: you may read and write a thread only if you are one of its participants, and an attached document is checked against the account that is reading it. A compact panel cannot add access it does not have. The full Messages page keeps what needs room: attaching a document to a message, the "new messages" divider, and deleting your own message. The header carries a link to it. {% endcomment %} {% comment %} The button is fixed bottom-right and floats over whatever is under it, so every page reserves that much space at the bottom of its content. The rule lives with the button, which means a page that does not render the dock gets no dead gap. {% endcomment %}
